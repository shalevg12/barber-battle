# barberCommon — פרסומות משותפות למשחקי אבי וקוקו

מודול JavaScript עצמאי למשחקים ב-GitHub Pages, ללא שרת וללא תשלומים.

## חיבור למשחק

```html
<script src="https://shalevg12.github.io/barber-battle/barberCommon/ads.js?v=2"></script>
<script>
const ads = window.BarberCommonAds?.create({
  gameId: 'your-game-id',
  deathsPerAd: 2,
  durationSeconds: 15,
  playerId: () => 'guest'
});

function onGameOver() { ads?.recordGameOver(); }
function onRemoveAdsClick() { ads?.removeAds(); }
```

## כללים

- הפרסומת מופיעה אחרי כל שתי פסילות באותו משחק, ולעולם לא תוך כדי סיבוב.
- צפייה ראשונה: אפשר לדלג אחרי 5 שניות. צפייה שנייה: אחרי 3 שניות. מהצפייה השלישית ואילך כפתור הדילוג זמין מיד.
- כל מודעה מסתיימת אוטומטית אחרי 15 שניות. שחקן יכול תמיד לבחור לצפות בה עד הסוף.
- כפתור "הסר פרסומות" הוא בדיחה בלבד ומציג: **"סתם, אי אפשר לבטל פרסומות 😅 אבל העיקר הבריאות והתסרוקת! ✂️"**. שום פטור מפרסומות לא נוצר.
- ספירת הצפיות והפסילות נשמרת ב-`localStorage` תחת `barberCommon:ads:v1`, לתאימות למכשירים קיימים. נתוני `adFree` ישנים מתעלמים ונמחקים בשמירה הבאה.
- ספירת הפסילות נפרדת לכל `gameId`; ספירת הפרסומות משותפת למשחקים המשתמשים באותו `playerId` באותו דפדפן.
- `guest` מזהה שחקן אורח רק במכשיר ובדפדפן הנוכחיים, ולא מאמת אדם. לא נעשה סנכרון בין מכשירים.
- המדיה היא WebP מונפש של אבי וקוקו המקודד בתוך `ads.js` ואינו דורש שירות חיצוני.

## אירוח

כרגע המודול נמצא ברפו `barber-battle` תחת `barberCommon/`. המשחק `flappyBarber` טוען אותו לפי כתובת זו. בעתיד אפשר להעביר אותו לרפו נפרד ולהחליף את כתובת הסקריפט במשחקים.
